# Social Dashboard Workflow

> **Invoke with**: `/social-dashboard`

This workflow automatically spins up the local Streamlit web server to visualize live GoHighLevel integration metrics across all connected social pipelines (Facebook, LinkedIn, Instagram, etc.).

// turbo-all

1. Run the Streamlit dashboard in the background:
   ```bash
   make dashboard
   ```

2. Remind the user they can access the dashboard at `http://localhost:8501`.
